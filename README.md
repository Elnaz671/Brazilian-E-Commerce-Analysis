Brazilian E-Commerce Data Analysis

An end-to-end data analysis project exploring Brazilian e-commerce performance using Python, and Power BI.

Project Overview

This project analyzes the Brazilian E-Commerce Public Dataset by Olist to explore customer behavior, payment methods, product performance, seller activity, and sales trends.

The goal is to transform raw e-commerce data into meaningful insights that support data-driven business decisions.

Business Questions

Which product categories perform best?

What payment methods do customers use?

How do sales and order patterns change over time?

What can customer and seller data tell us about business performance?

Which trends could help improve the customer experience?

Tools & Technologies

Python — data analysis and processing

Pandas — data cleaning and manipulation

Matplotlib — data visualization

Power BI — interactive dashboards and reporting

Jupyter Notebook — exploratory data analysis

Project Structure

data/ — datasets and data files

notebook/ — exploratory analysis

scripts/ — Python scripts

dashboard/ — Power BI dashboard files

Workflow

Explore the dataset and understand the business context.

Clean and prepare the data.

Analyze sales, customers, payments, products, and sellers.

Visualize relevant patterns and trends.

Present insights through analysis and dashboards.

Dataset

Brazilian E-Commerce Public Dataset by Olist.

The dataset contains anonymized Brazilian e-commerce order information from 2016–2018.

Key findings and business recommendations will be added after validating the results of the analysis.
